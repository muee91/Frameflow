| 标签 | 含义 |
| --- | --- |

## 第一阶段必须全部满足的验收标准

### A. 项目与素材

- 新用户打开后能直接创建项目、选择视频/独立录音、看到机位来源。
- 相同素材复制到不同硬盘/目录，内容身份相同；同名异内容不能误认。
- 长扫描/哈希期间可见实际文件和真实字节进度，可取消；不修改原片。
- 目录缺失、无权限、损坏媒体、源文件仍在写入、未知时长和无音轨都有明确处理。
- 分享数据不含绝对设备路径、模型密钥、用户运行日志；重链后校验内容身份。

### B. 同步与可观察性

- 覆盖正/负整体错位、局部跳变/时间码重置、长时漂移、无有效时间码、午夜/多天、同台词多次 Take、静音/噪声/无共同内容、音视频解码延迟。
- 有可靠音频时不能被错误时间码强行覆盖；证据冲突、歧义与低支持关系可见。
- 无证据素材不能自动得到可信起点；不静默压缩真实间隙、剪掉未匹配素材或人为堆到前片末尾。
- 确定性合成常量偏移达到 <= 1 项目帧误差；漂移与局部映射分别检查片头、中段、片尾，并记录实际误差，不能只比较片头。
- 阶段、done/total、当前文件、最近活动、心跳/最后推进、原因码可查询；未知总量不显示假百分比。
- 静默进程也能取消；进程退出后才结束；取消胜过迟到成功。重试保留旧记录，任务失败不杀死后续队列。
- 重启后状态可解释，旧运行中任务标中断；不能自动宣告完成或偷偷续算。

### C. 人工核对

- 实际视频与独立录音可播放、跳转、单路监听；显示每路源位置及公共时间位置。
- 对片头、中段、片尾检查声音与动作，不把多个 HTML 媒体元素的表面同时播放当作帧精确保证。
- 支持起点、分段错位和漂移的适当修正；完整保留引擎建议、人工理由、修订与撤销依据。
- 不支持编码、源离线、媒体改变、并发旧版本提交等明确阻止误确认/误交付。

### D. 两类成果分别验收

| 成果 | 要求 |
| --- | --- |
| 完整多轨同步母版 | 原片完整来源范围；视频与所有独立音频/声道保留；真实间隙；漂移副本可追溯；不以扁平混音替代 |
| 原生 multicam | 目标软件识别为原生多机位对象；可切换角度；参考录音正确；连续播放和起中末核对；保存重开、素材迁移重链通过 |

每个结果记录 OS、NLE 版本/发行来源、帧率/DF/NDF、音频采样率/声道、编码、片数、时长、未匹配/排除项、导入日志与核对结果。FCP 仅 macOS；其它软件按实际支持系统记录。未通过的软件在界面和文档不显示“支持”。

## 本轮验证证据

- MirrorOrder 只读基线 `88e585e1`：96 项底层定向测试通过；未移植旧代码；旧 main CI 失败状态不当作新产品证据。
- Align 官方 v0.3.3 Linux 包 SHA256：`3098b7c3d98db1058c1131a13ccdaa1f208c20f4b9504d8a70c647e332a7f307`。单独解包运行 CLI，无系统安装，无捆绑提交。
- 30 秒单对合成 WAV + 1.250 秒延迟：真实 CLI 产生 12 anchors，误差约 17 微秒。这是局部探针，不能推广到不同输入次序、长片、重复对白或所有编码。
- 本地收集 83 项测试，81 项通过、2 项 Windows 专属测试按平台跳过；包括两个 opt-in 真实 Align 用例。覆盖 API、状态竞争、媒体、进程、引擎、修订与静态资源。使用 Python 3.12、真实 FFmpeg 7.1.5 / Align 0.3.3；不能把 Windows skip 当作通过。
- 完整合成处理链：60 秒确定性声音、两路 H.264/AAC-LC MP4、独立立体 PCM WAV，1.250 秒已知错位。真实扫描/FFprobe/哈希/Align→全部 proposed→逐片人工理由→manifest→异步 FCPXML 下载通过，偏移误差 <= 25fps 的一帧。XML 验证了三份素材、立体音频、两条 sequence 以及 multicam/mc-angle/mc-clip；没有在 NLE 导入。
